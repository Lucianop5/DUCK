# ADR-0007 — UUID como clave primaria

- **Fecha:** 2026-10-23
- **Estado:** Aceptada

## Contexto

Los identificadores se exponen en URLs y en la futura API de integración. No deben revelar volumen
ni permitir enumeración de recursos.

## Alternativas

1. Enteros autoincrementales: compactos, enumerables.
2. UUID v4: no enumerable, generado por la aplicación.
3. UUID v7: ordenable, mejor localidad, mayor complejidad.

## Decisión

UUID v4 (`@default(uuid())`, `CHAR(36)` en MySQL) en todas las tablas de dominio y de
autenticación.

## Consecuencias

- URLs como `/expenses/3f2a…/edit`.
- Índices algo más grandes, irrelevante a esta escala.
- Migrar a UUID v7 más adelante no cambia el contrato.
